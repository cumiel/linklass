# Linklass Legal Documents

Public-facing legal documents for the Linklass app.

→ Live:
- 개인정보처리방침 / Privacy Policy: https://cumiel.github.io/linklass/
- 이용약관 / Terms of Service: https://cumiel.github.io/linklass/terms.html

각 HTML 파일에 한국어/영문이 모두 포함되어 있고, 토글 버튼으로 전환 가능합니다.

## 파일 구성

- `index.html` — 개인정보처리방침 (Privacy Policy)
- `terms.html` — 이용약관 (Terms of Service)

## 사용처

- App Store Connect → 앱 정보 → 개인정보처리방침 URL / 이용약관 URL
- Google Play Console → 앱 정보 → 개인정보처리방침 URL
- 앱 설정 → 이용약관·개인정보처리방침 메뉴
