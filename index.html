Cumiel Inc.(이하 "운영자")은 Linklass(이하 "서비스") 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 운영자가 수집·이용하는 개인정보의 항목, 목적, 보유 기간 및 이용자의 권리를 안내합니다.

1. 수집하는 개인정보 항목

회원 가입 시 (필수)

  • 이메일 주소
  • 이름 (소셜 로그인 제공자가 제공하는 경우)
  • 프로필 이미지 URL (소셜 로그인 제공자가 제공하는 경우)
  • 소셜 로그인 고유 식별자 (Google Sub ID, Apple User ID)

서비스 이용 중 (선택)

  • 닉네임, 자기소개, 프로필 이미지(직접 업로드)
  • 클래스 정보 (클래스명, 설명, 아이콘 이미지)
  • 수업 일정, 예약 내역, 수강생 등록 정보

자동 수집

  • FCM(Firebase Cloud Messaging) 푸시 토큰
  • 기기 광고용 비식별 ID
  • 앱 버전, OS 버전 등 기본 기기 정보
  • 결제·구독 정보 (Apple App Store / Google Play 결제 기록)

4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 외부에 판매·제공하지 않습니다. 다음의 경우만 예외입니다.

  • 법령에 근거하거나 수사기관의 적법한 요청이 있는 경우
  • 인앱 결제 처리를 위해 Apple/Google이 결제 정보를 자체적으로 보관·처리하는 경우

5. 개인정보 처리 위탁

원활한 서비스 운영을 위해 다음 업체에 일부 처리를 위탁하고 있습니다.

6. 정보주체의 권리·의무

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람: 앱 내 프로필 화면에서 본인 정보 확인
  • 정정: 앱 내 프로필 편집 기능 사용
  • 삭제(회원 탈퇴): 앱 내 "계정 삭제" 기능 사용
  • 처리 정지: 운영자에게 직접 요청 (아래 연락처)

회원 탈퇴 시 모든 개인정보가 즉시 삭제되며 복구할 수 없습니다.

7. 만 14세 미만 아동의 개인정보

서비스는 만 14세 미만 아동을 직접적인 대상으로 하지 않습니다. 만 14세 미만이 가입한 사실이 확인되면 즉시 해당 계정과 정보를 삭제합니다.

8. 개인정보의 안전성 확보 조치

  • HTTPS 암호화 통신
  • Firestore Security Rules를 통한 접근 제어
  • 인증된 사용자만 본인 데이터에 접근 가능
  • Firebase Auth의 보안 표준 적용

Cumiel Inc. ("we", "us", or "operator") respects your privacy. This policy explains what personal information we collect through the Linklass app ("Service"), how we use it, and your rights regarding your data.

At Sign-Up (Required)

  • Email address
  • Name (if provided by social login)
  • Profile image URL (if provided by social login)
  • Social login identifier (Google Sub ID, Apple User ID)

During Service Use (Optional)

  • Nickname, bio, uploaded profile image
  • Class information (name, description, icon image)
  • Lesson schedule, bookings, student enrollment records

Automatically Collected

  • FCM push token
  • Device advertising identifier (non-personally identifiable)
  • App version, OS version (for diagnostics)
  • Subscription and purchase records (Apple/Google)

6. Your Rights

You may exercise the following rights at any time.

  • Access: View your info in the in-app profile screen
  • Correction: Edit your profile in the app
  • Deletion (account closure): Use the in-app "Delete Account" feature
  • Restriction of Processing: Contact us directly (see below)

Upon account deletion, all personal data is removed immediately and cannot be recovered.

7. Children's Privacy

The Service is not directed to children under 14. If we become aware that a user under 14 has created an account, we delete that account and associated data immediately.

8. Security Measures

  • HTTPS-encrypted transport
  • Firestore Security Rules for access control
  • Authentication-based access (users can only see their own data)
  • Firebase Auth security standards
